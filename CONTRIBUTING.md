# Contributing

Thanks for your interest in contributing to PDF Expert!

## Getting Started

1. Fork the repository
2. Clone your fork: `git clone https://github.com/your-username/pdfexpert.git`
3. Create a branch: `git checkout -b feature/my-feature`
4. Make your changes
5. Run lint: `yarn lint`
6. Commit with a descriptive message
7. Push and open a Pull Request

## Development Setup

See [README.md](README.md) for prerequisites and setup instructions.

## Guidelines

- Keep PRs focused — one feature or fix per PR
- Follow existing code style (TypeScript, Tailwind CSS)
- UI text should be in english (i18n can be implemented later)

## Reporting Issues

Open an issue with:
- What you expected
- What happened
- Steps to reproduce
- Browser/OS/Node version if relevant
